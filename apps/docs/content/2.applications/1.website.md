## `@frigear-nu/website`

The main website in this workspace, built with Nuxt 4 and shared Frigear modules and packages. It is the successor to
the [previous Nuxt website](https://github.com/Frigear-nu/nuxt-frigear-nu).

### What it contains

- The website application lives in `apps/website`.
- Its public content is organized under `content/da` and `content/en`, with language selection provided by
  `@nuxtjs/i18n`.
- Its dependencies include the shared `@frigear-nu/users` module and `@frigear-nu/ui` package.
- The workspace also provides a reusable [`@frigear-nu/base` layer](/layers/base) for website applications.

### Run it locally

From the repository root, install workspace dependencies and start the app:

```bash
pnpm install
pnpm --filter @frigear-nu/website dev
```

See the [local development guide](/getting-started/local-development) for setup and validation commands.
