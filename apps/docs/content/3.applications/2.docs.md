`@frigear-nu/docs` is a [Docus](https://docus.dev) app under `apps/docs`. It documents the whole workspace: modules,
layers, packages and the applications. Product documentation for end users belongs in `apps/website`, not here.

```bash
pnpm --filter @frigear-nu/docs dev
pnpm --filter @frigear-nu/docs build
```

Page conventions, ordering and the module page template are in the
[docs README](https://github.com/Frigear-nu/frigear-nu/blob/main/apps/docs/README.md#documentation-conventions).
