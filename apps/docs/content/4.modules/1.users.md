## `@frigear-nu/users`

This [Nuxt module](https://nuxt.com/docs/4.x/guide/modules) provides user-related functionality. The website includes it as a workspace dependency. It uses
[`@frigear-nu/module-kit`](/modules/module-kit) to register its database schema.

### Module modes

The module supports two modes, configured in `nuxt.config.ts`:

```ts
export default defineNuxtConfig({
  users: {
    mode: 'server',
  },
})
```

- `server` is the default and registers the module's user table schema.
- `client` is for applications that rely on a central authentication server rather than managing authentication
  themselves.

### User table

The default SQLite schema includes an auto-incrementing `id`, a required `name`, a unique required `email`, optional
`password` and `avatar` fields, and `createdAt` / `updatedAt` timestamps. Other modules can add columns through the
module-kit schema extension helpers.

The server mode also supports schema configuration through `users.settings.schemas.users`. See the
[module-kit guide](/modules/module-kit) for how table extensions are registered and merged.
