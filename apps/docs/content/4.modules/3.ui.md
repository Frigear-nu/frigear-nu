## `@frigear-nu/ui`

`@frigear-nu/ui` is a [Nuxt module](https://nuxt.com/docs/4.x/guide/modules) that registers shared Vue components and auto-imports composables and utilities for
Frigear applications. It also integrates with Nuxt UI, Monaco Editor, and optionally Nuxt i18n.

The module registers global form inputs such as date, currency, tag, interval, and URL inputs, along with other
on-demand components. It also provides a confirmation dialog composable.

The package's [playground](https://github.com/Frigear-nu/frigear-nu/tree/main/packages/ui/playground) is available for
developing and previewing UI features.
