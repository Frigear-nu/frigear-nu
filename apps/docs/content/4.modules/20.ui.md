## `@frigear-nu/ui`

`@frigear-nu/ui` is a [Nuxt module](https://nuxt.com/docs/4.x/guide/modules) that registers shared Vue components and auto-imports composables and utilities for
Frigear applications. It also integrates with Nuxt UI, Monaco Editor, and optionally Nuxt i18n.

The module registers global form inputs such as date, currency, tag, interval, and URL inputs, along with other
on-demand components. It also provides a confirmation dialog composable.

The package's [playground](https://github.com/Frigear-nu/frigear-nu/tree/main/packages/ui/playground) is available for
developing and previewing UI features.

## `useConfirmDialog`

`useConfirmDialog` is an auto-imported composable that opens a modal asking the user to confirm an action. It is built
on Nuxt UI's `useOverlay` and renders the module's `ConfirmDialog` component.

The composable returns a function. Call it with the dialog options and `await` the result: it resolves to `true` when
the user confirms and `false` when they cancel.

```vue
<script setup lang="ts">
const confirm = useConfirmDialog()

async function removeItem() {
  const confirmed = await confirm({
    title: 'Delete item?',
    description: 'This action cannot be undone.',
    confirmText: 'Delete',
  })

  if (!confirmed) return

  await $fetch('/api/items/1', { method: 'DELETE' })
}
</script>
```

### Options

| Option        | Type     | Description                                                   |
|---------------|----------|---------------------------------------------------------------|
| `title`       | `string` | Required. Heading of the dialog.                              |
| `description` | `string` | Optional. Supporting text shown below the title.              |
| `confirmText` | `string` | Optional. Label of the confirm button. Defaults to `Confirm`. |

::note
The dialog is not dismissible by clicking outside of it or pressing escape, so the promise only resolves through the
**Cancel** or confirm button. The dialog is destroyed once it closes.
::

The `ConfirmDialogOptions` type is exported from the module's composables.
