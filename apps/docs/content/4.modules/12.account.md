The account area (profile, email, password, security) as a [Nuxt module](https://nuxt.com/docs/4.x/guide/modules).

## Design

- **Reuses [Users](/modules/users).** It updates the same `users` table and reuses its session helpers
  (`mapUserToSession`, `hashPassword` / `verifyPassword`) instead of registering its own table or duplicating auth logic.
- **Opt-in pages** for profile and security, built with [`@nuxt/ui`](https://ui.nuxt.com).
- **Menu tiles.** When [Menu](/modules/menu) is installed, "Profile" and "Security" tiles are contributed, and an optional
  dashboard page lists them.
- **Passkeys** are managed through `useUserPasskeys` from Users, when WebAuthn is enabled there.

## Quick Setup

```bash
npx nuxt module add @frigear-nu/account
```

`@frigear-nu/users` must be installed in the host app.

```ts
export default defineNuxtConfig({
  modules: [
    '@nuxthub/core',
    '@frigear-nu/users',
    '@frigear-nu/menu', // optional - enables the dashboard tiles/page
    '@frigear-nu/account',
  ],
  account: {
    settings: {
      pages: {
        profile: true, // or a custom path, e.g. '/me'
        security: true,
        // Only registered when `@frigear-nu/menu` is also installed.
        index: true,
      },
    },
  },
})
```

## API routes

- `POST /api/account/profile` - updates `name` / `avatar`.
- `POST /api/account/change-email` - updates `email` (rejects if already taken by another user).
- `POST /api/account/change-password` - verifies `currentPassword` and updates to `newPassword`.

All three require an authenticated session and re-map the updated user into it.

## Composable

```ts
const { updateProfileDetails, changeEmailAddress, changePassword, pending, error } = useAccount()

await updateProfileDetails({ name: 'Ada Lovelace' })
await changeEmailAddress({ email: 'ada@example.com' })
await changePassword({ currentPassword: 'old', newPassword: 'new-password', confirmNewPassword: 'new-password' })
```

## Translations

The module registers `da` and `en` locale files with [module-kit](/modules/module-kit#translations-i18n) under the
`account.*` namespace. Without `@nuxtjs/i18n` the English defaults are used. Override any string in your app's
`i18n/locales/<code>.json` (see
[overriding module strings](/modules/module-kit#overriding-module-strings-in-your-app)):

```json
{ "account": { "profile": { "title": "My details" } } }
```

Key groups: `title`, `menu.*`, `identificationCode.*`, `profile.*`, `documents.*` and `security.*`. The full list is
`src/runtime/i18n/lang/en.json` in the package.
