The account area (profile, email, password, security) as a [Nuxt module](https://nuxt.com/docs/4.x/guide/modules).

## Design

- **Reuses [Users](/modules/users).** It updates the same `users` table and reuses its session helpers
  (`mapUserToSession`, `hashPassword` / `verifyPassword`) instead of registering its own table or duplicating auth logic.
- **Opt-in pages** for profile and security, built with [`@nuxt/ui`](https://ui.nuxt.com).
- **Menu tiles.** When [Menu](/modules/menu) is installed, "Profile" and "Security" tiles are contributed, and an optional
  dashboard page lists them.
- **Passkeys** are managed through `useUserPasskeys` from Users, when WebAuthn is enabled there.

## Quick Setup

```bash
npx nuxt module add @frigear-nu/account
```

`@frigear-nu/users` must be installed in the host app.

```ts
export default defineNuxtConfig({
  modules: [
    '@nuxthub/core',
    '@frigear-nu/users',
    '@frigear-nu/menu', // optional - enables the dashboard tiles/page
    '@frigear-nu/account',
  ],
  account: {
    settings: {
      pages: {
        profile: true, // or a custom path, e.g. '/me'
        security: true,
        // Only registered when `@frigear-nu/menu` is also installed.
        index: true,
        documents: true, // lists `documents` below, at /account/documents
      },
      documents: [
        { id: 'handbook', label: { da: 'Håndbog', en: 'Handbook' }, path: '/assets/files/handbook.pdf' },
        { id: 'crew', label: 'Crew plan', path: '/assets/files/crew.pdf', roles: ['admin', 'crew'] },
      ],
      // Confirm a new email address from its inbox before it takes effect (default: applied immediately).
      verifyEmailChange: true,
    },
  },
})
```

## API routes

- `POST /api/account/profile` - updates `name` / `avatar`.
- `POST /api/account/change-email` - updates `email` (rejects if already taken by another user).
- `POST /api/account/change-password` - verifies `currentPassword` and updates to `newPassword`.

All three require an authenticated session and re-map the updated user into it. A successful password change also
emails the user a notice (a failing mail never undoes the change); this needs
[`@frigear-nu/notify`](/modules/notify), which the module installs.

### Documents

`settings.documents` lists downloadable files on an opt-in page (`pages.documents`, default `/account/documents`, with a
tile on the dashboard). `label` is a string or a locale map, and `roles` limits who the file is *listed* for (the
session user's `role`).

::warning
`roles` only filters the list. A file served from `public/` can be fetched by anyone who knows its URL; put sensitive
files behind a server route if that matters.
::

### Verified email change

With `settings.verifyEmailChange`, `change-email` responds `{ verificationRequired: true }` and changes nothing yet.
It stores the request in `account_email_changes` and emails a link to the **new** address:

- `GET /auth/verify-email-change?code=` applies the change (single use, valid 24 hours), marks the address verified,
  and emails the **old** address a notice with a revert link. Redirects to the profile page with `?email-changed=1`
  (or `?error=email-change` for a bad/used/expired code, or an address that was taken in the meantime).
- `GET /auth/revert-email-change?code=` puts the old address back (single use, valid 7 days), signs the user out and
  redirects to the login page with `?email-reverted=1` (or `?error=email-revert`).

The emails are plain notifications dispatched through the configured notify driver.

## API tokens page

`settings.pages.apiTokens` (`true` for `/account/api-tokens`) adds a page where users create and revoke personal API
tokens (see [`@frigear-nu/auth`](/modules/auth)). A new token is shown once, with the scopes and expiry the user chose.
The page needs `@frigear-nu/auth`, which `@frigear-nu/users` installs.

`settings.mcp` (default `false`) exposes the account's MCP tools and shows the "Connect to MCP" card on this page. See [MCP](/modules/mcp).

## Composable

```ts
const { updateProfileDetails, changeEmailAddress, changePassword, pending, error } = useAccount()

await updateProfileDetails({ name: 'Ada Lovelace' })
await changeEmailAddress({ email: 'ada@example.com' })
await changePassword({ currentPassword: 'old', newPassword: 'new-password', confirmNewPassword: 'new-password' })
```

## Translations

The module registers `da` and `en` locale files with [module-kit](/modules/module-kit#translations-i18n) under the
`account.*` namespace. Without `@nuxtjs/i18n` the English defaults are used. Override any string in your app's
`i18n/locales/<code>.json` (see
[overriding module strings](/modules/module-kit#overriding-module-strings-in-your-app)):

```json
{ "account": { "profile": { "title": "My details" } } }
```

Key groups: `title`, `menu.*`, `identificationCode.*`, `profile.*`, `documents.*` and `security.*`. The full list is
`src/runtime/i18n/lang/en.json` in the package.
