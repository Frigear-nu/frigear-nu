## Subpath exports

| Import | Contents |
| --- | --- |
| `@frigear-nu/ui` | The Nuxt module |
| `@frigear-nu/ui/components/*` | A component file, for example `@frigear-nu/ui/components/TagInput` or `.../PageHeading` |
| `@frigear-nu/ui/composables`, `@frigear-nu/ui/composables/*` | The composables above |
| `@frigear-nu/ui/utils` | The pure helpers: `errorMessage`, `errorToToast`, `stripLocale`, `formatDate`, `formatDateTime`, `formatTime`, `formatDateRange`, `statusColor`, `surfaceClass`, `tableUi`, `numericColumn`, `emptyCell`, `nextTableSort`, `tableSortQuery`, `tablePageRange` |
| `@frigear-nu/ui/types` | The types used by the components' props and the helpers |
| `@frigear-nu/ui/translated` | `Translated` helpers (below) |
| `@frigear-nu/ui/markdown` | `renderMarkdown`, `withMdcData` |
| `@frigear-nu/ui/money` | Money helpers (below) |

```ts
// @frigear-nu/ui/translated
type Translated = string | Record<string, string> // one text for every language, or locale -> text

translate(value, locale = 'en', fallback?): string // locale, else fallback, else 'en', else the first non-empty entry
hasTranslation(value, locale): boolean // text for exactly that locale
readTranslated(value, locale): string
writeTranslated(value, locale, text): Translated | undefined // plain strings stay plain; empty entries dropped
expandTranslated(value, locale): Translated | undefined // plain string to a per-locale map
collapseTranslated(value, locale): Translated | undefined // map to one string
filledLocales(value): string[]
isLocaleCode(code): boolean // da, en-GB, pt_BR
```

```ts
// @frigear-nu/ui/markdown
renderMarkdown(source: string): string // escapes everything; supports **bold**, _italic_, [text](https://...) links and paragraphs
withMdcData(source: string, data?: Record<string, unknown>): string // prepends data as frontmatter so MDC resolves {{ name }}

// @frigear-nu/ui/money (amounts are in the currency's minor unit)
type Currency = { name?: string, code: string, symbol: string }
currencyDigits(code: string): number // minor-unit digits from Intl: 2 for EUR, 0 for JPY, 3 for KWD
formatMoney(amount: number, currency: string, locale?: string): string // formatMoney(15000, 'DKK', 'da') -> '150,00 kr.'
fromCents(amount, code = 'EUR'): number | null | undefined
toCents(value, code = 'EUR'): number | null | undefined
currencyOptions(locale = 'en'): Currency[]
```

## Translations

The module contributes shared `da` and `en` strings (when `@nuxtjs/i18n` is installed) that other modules and your app
reuse. Override any of them in your app's `i18n/locales/<code>.json` (see
[overriding module strings](/modules/platform/module-kit/i18n#overriding-module-strings-in-your-app)); because other modules use
these keys, an override applies everywhere they appear.

| Namespace | Keys |
| --- | --- |
| `common` | `or`, `close`, `information`, `back`, `current`, `visit`, `refresh`, `expiresIn` |
| `actions` | `selectFiles`, `removeAllFiles`, `view`, `backTo`, `save`, `select`, `change`, `cancel` |
| `locale` | `switch` |
| `translated` | `translate`, `filled`, `missing`, `addLanguage`, `singleLanguage` (used by `TranslatedInput`) |
| `markdown` | `write`, `preview`, `empty` (used by `MarkdownTextarea`) |
| `patterns` | `notSet`, `moreActions`, `actionsFor`, `viewAll`, `copied`, `genericError`, `open`, `edit`, `delete` (used by the page components and helpers, [below](#the-patterns-strings)) |

```json
{ "actions": { "cancel": "Never mind" } }
```

### The `patterns` strings

The page components and helpers read the `patterns` namespace through `useUiT('patterns')`:

| Key | Used by |
| --- | --- |
| `notSet` | `DescriptionList` for a missing value ("Not set") |
| `moreActions` | `RowMenu` button label when no `subject` is given |
| `actionsFor` | `RowMenu` button label with a subject: "Actions for {subject}" |
| `viewAll` | `ListCard` link label (`toLabel`) |
| `copied` | `useCopyToClipboard` toast |
| `genericError` | `errorMessage` when an error carries no message |
| `open`, `edit`, `delete` | The standard labels of row-menu entries |
| `sortBy`, `sortedAsc`, `sortedDesc` | `useTableSort` header labels for screen readers ("Sort by {column}, now ascending") |
| `range`, `noRows`, `rowsPerPage` | `TablePagination` ("{from}–{to} of {total}", "Rows per page") |

There are two ways to change one:

- **Per use**: every built-in string is also a prop (`empty` on `DescriptionList`, `toLabel` on `ListCard`,
  `subject` on `RowMenu`), so a single page can say something more specific.
- **Everywhere**: override the key in your app's `i18n/locales/<code>.json`. Other modules use these keys, so the
  override applies wherever they appear.

```json
{ "patterns": { "notSet": "Missing", "viewAll": "See everything" } }
```

Module-specific text does not belong here: modules ship their own namespace and read it with `useModuleT`.
