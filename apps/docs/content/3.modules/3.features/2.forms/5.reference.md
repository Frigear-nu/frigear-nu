## Hooks

Nitro runtime hooks, registered from a server plugin with `nitro.hooks.hook(name, handler)`.

| Hook | When | Payload |
| --- | --- | --- |
| `forms:authorize` | A staff route is called | `{ event, userId: number, allowed: boolean }`; set `allowed = true` to let the user in |
| `forms:submitted` | A valid submission was received (and stored unless `storage: 'none'`) | `SubmittedContext` (below) |
| `forms:captcha:verify` | A captcha token must be verified | `{ event, provider, token, ip, formId?, secretKey?, secretSource?: 'form' \| 'env' \| 'unset', valid: boolean \| undefined }`; set `valid` to decide, left `undefined` the provider is asked |
| `forms:delivered` | Delivery finished (only fires when a handler delivered or one failed) | `{ submissionId: string \| null, formSlug, status: 'delivered' \| 'failed', error? }` |

```ts
type SubmittedContext = {
  event: H3Event
  form: { id: string, slug: string, name: string, version: number, definition: FormDefinition }
  answers: Record<string, unknown> // validated; file fields hold the file names
  files: { fieldKey: string, filename: string, contentType: string, size: number, pathname: string | null }[]
  locale: string
  userId: number | null
  submissionId: string | null // null when storage is 'none'
  stored: boolean
  delivered: boolean // set true once the handler delivered; throw to mark delivery failed
}
```

```ts
nitroApp.hooks.hook('forms:submitted', async (ctx) => {
  await fetch('https://example.com/hook', { method: 'POST', body: JSON.stringify(ctx.answers) })
  ctx.delivered = true
})
```

- The built-in email delivery listens to `forms:submitted` and mails `delivery.email` through `@frigear-nu/notify`.
- For `storage: 'db'` a failing listener sets `deliveryStatus = 'failed'` (with the error) and the visitor still gets
  success; **Deliver again** in the admin re-runs the hooks. For `storage: 'none'` nothing else keeps the answers, so a
  failure is returned as `502`.

## Routes

Public routes are under `/api/forms`, staff routes under `/api/admin/forms`. Build paths with `formsApi` from
`@frigear-nu/forms/utils` (`formsApi.admin.form(id)`, `formsApi.admin.secret(id, key)`, ...) instead of literals.
"Staff" means the `forms:manage` scope plus the `forms:authorize` policy; staff routes accept bearer tokens with that
scope, except the ones marked **session**, which mint or remove access credentials (`403 session_required` for a bearer
token). The static `import` and `submissions` segments win over `:id` under `/api/admin/forms`.

Errors carry `data.code` (`not_found`, `forbidden`, `conflict`, `validation_failed`, `session_required`, ...). Paginated
lists answer `{ items, total, page, pageSize }` and take `page`, `pageSize` (at most `100`, default `20`), `sort`,
`order` (`asc` / `desc`) and their filters as query parameters.

| Method | Path | Auth | Status | Purpose |
| --- | --- | --- | --- | --- |
| `GET` | `/api/forms/:slug` | Form access | `200` | Published definition without `delivery` |
| `GET` | `/api/forms/:slug/access` | None | `200` | What the page needs to choose between the form, a gate and "not found" |
| `POST` | `/api/forms/:slug/submit` | Form access | `200` | Submit answers (rate limited; `400` with `data.issues`) |
| `GET` | `/api/admin/forms` | Staff | `200` | Paginated forms with submission counts; `q` (name, slug), `status`, `archived=false`; sort `updatedAt` (default, desc), `createdAt`, `name`, `slug`, `status`, `submissionCount` |
| `POST` | `/api/admin/forms` | Staff | `201` | Create a form (`409 conflict` for a taken slug) |
| `POST` | `/api/admin/forms/import` | Staff | `200` | Import definitions; `{ inserted, skipped }` |
| `GET` | `/api/admin/forms/:id` | Staff | `200` | One form, with `submissionCount` |
| `PATCH` | `/api/admin/forms/:id` | Staff | `200` | Update; a changed definition bumps `version` |
| `DELETE` | `/api/admin/forms/:id` | Staff | `204` | Soft delete: archives the form (status `archived`); it and its submissions are kept, and a `PATCH` can publish it again |
| `POST` | `/api/admin/forms/:id/clone` | Staff | `201` | Clone into a draft |
| `GET` | `/api/admin/forms/:id/submissions` | Staff | `200` | Paginated submissions; `deliveryStatus` filter; sort `createdAt` (default, desc), `deliveryStatus`, `locale` |
| `GET` | `/api/admin/forms/:id/tokens` | Staff | `200` | The form's access tokens (an array) |
| `POST` | `/api/admin/forms/:id/tokens` | Staff, **session** | `201` | Create a token; the token is only in this response |
| `DELETE` | `/api/admin/forms/:id/tokens/:tokenId` | Staff, **session** | `204` | Revoke a token (the row stays listed with `revokedAt`) |
| `GET` | `/api/admin/forms/:id/password` | Staff | `200` | Whether a password is set (`{ set }`) |
| `PUT` | `/api/admin/forms/:id/password` | Staff, **session** | `200` | Set the password `{ password }` (6-200 chars); `{ set: true }` |
| `DELETE` | `/api/admin/forms/:id/password` | Staff, **session** | `204` | Remove the password |
| `GET` | `/api/admin/forms/:id/secrets` | Staff | `200` | Names and sources of secrets (`{ keys, captcha, unreadable }`) |
| `PUT` | `/api/admin/forms/:id/secrets/:key` | Staff, **session** | `200` | Write one secret `{ value }`; answers the secrets summary (`400` for an unknown key) |
| `DELETE` | `/api/admin/forms/:id/secrets/:key` | Staff, **session** | `204` | Remove one secret (`400` for an unknown key) |
| `GET` | `/api/admin/forms/submissions/:id` | Staff | `200` | One submission |
| `GET` | `/api/admin/forms/submissions/:id/files/:fileId` | Staff | `200` | Download an uploaded file |
| `POST` | `/api/admin/forms/submissions/:id/redeliver` | Staff | `200` | Run the delivery hooks again; `{ deliveryStatus, deliveryError }` |

## Database

| Table | Purpose |
| --- | --- |
| `forms` | `slug`, `name`, `status` (`draft`, `published`, `archived`), `definition`, `version` |
| `form_submissions` | Answers, `definitionSnapshot`, `formVersion`, `userId`, `locale`, `deliveryStatus` (`none`, `pending`, `delivered`, `failed`) and `deliveryError` |
| `form_submission_files` | Blob pathname, filename, content type and size per uploaded file |
| `form_access_tokens` | Per-form API tokens: `tokenHash`, `prefix`, `lastUsedAt`, `revokedAt` |
| `form_access` | One row per password-protected form: `passwordHash` |
| `form_secrets` | One row per form: `secrets` (encrypted JSON map of namespaced keys) |

Files are only downloadable by staff. Generate and commit migrations for all six tables in every host app and fixture
(see [Module Kit](/modules/platform/module-kit/database#migrations-and-database-backed-module-tests)).

## Translations

- **Module chrome** (buttons, stepper, admin) uses `useModuleT('forms')` with English fallbacks; the module contributes
  `forms.*` messages (`da`/`en`) through `registerLocales` (see [Module Kit](/modules/platform/module-kit/i18n)).
  Override any of them in your app's `i18n/locales/<code>.json` (see
  [overriding module strings](/modules/platform/module-kit/i18n#overriding-module-strings-in-your-app)), for example
  `{ "forms": { "actions": { "submit": "Send inquiry" } } }`.
- **Key groups**: `actions`, `step`, `success`, `error`, `embed`, `preview`, `field`, `value`, `status`, `delivery`,
  `validation`, `admin`, `schedule`, `access`, `menu`, `captcha`, `builder`.
- **Form content** lives in the definition as `{ da, en }` texts.
- **Validation messages** of the compiler's own rules use `forms.validation.*`; a field overrides them with
  `validation.message`.
