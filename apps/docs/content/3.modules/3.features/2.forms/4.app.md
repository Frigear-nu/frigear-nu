## Pages

| Page | Default path | Option |
| --- | --- | --- |
| Public form | `/forms/:slug` | `pages.form` |
| Admin list | `/admin/forms` | `pages.admin` |
| Admin editor | `/admin/forms/:id` | `pages.adminForm` |
| Submissions | `/admin/forms/:id/submissions` | `pages.adminSubmissions` |
| One submission | `/admin/forms/:id/submissions/:submissionId` | `pages.adminSubmission` |

Any can be a custom path string. The admin paths follow the configured [Admin](/modules/interface/admin) base.

## Components

| Component | Props | Notes |
| --- | --- | --- |
| `<FormRenderer>` | `slug?`, `form?`, `password?`, `preview?`, `locale?` | Renders a published form (by `slug`) or a given definition. Emits `submitted(id)` and `previewed(answers)`. |
| `<FormEmbed>` | `slug`, `title?`, `locale?`, `class?` | Embeds a published form, honoring its access settings. Registered globally. |
| `<FormPreview>` | `slug`, `name?`, `definition?`, `contentKey?` | Admin preview. |
| `<FormSubmissionView>` | `submission` | Renders a submission against the definition it was answered with. |

## Embedding in Markdown

`FormEmbed` is registered **globally**, so [Nuxt Content](https://content.nuxt.com) (MDC) resolves it in any collection
without a wrapper. Use the block syntax: the embed renders block elements, so inline `:form-embed{...}` would place
them inside a paragraph.

```md
::form-embed{slug="contact"}
::

::form-embed{slug="contact" title locale="da" class="max-w-2xl my-8"}
::
```

| Prop | Type | Default | Purpose |
| --- | --- | --- | --- |
| `slug` | `string` | none | Required. Slug of a published form. |
| `title` | `boolean` | `false` | Show the form's name as a heading. |
| `locale` | `string` | app locale | Overrides the locale of the form's translated texts. |
| `class` | `string` | none | Extra classes for the wrapper (it has `not-prose`). |

The embed uses `GET /api/forms/:slug/access` and follows the access settings:

| Form state | Renders |
| --- | --- |
| Open | The form, with a loading skeleton; success message or redirect handled by the renderer |
| Unknown or unpublished | A "could not be found" alert |
| `auth: 'user'` | A sign-in prompt linking to the login page (with a `redirect` back) |
| `auth: 'password'` | The password gate |
| `availability: 'api'` or `auth: 'token'` | Nothing (a console warning in development names the slug) |

## Composables

Auto-imported, also available from `@frigear-nu/forms/composables`.

```ts
useForm(slug: MaybeRefOrGetter<string>, password?: MaybeRefOrGetter<string | undefined>) // published definition
useFormAccess(slug: MaybeRefOrGetter<string>) // FormAccessInfoDto: access, signedIn, open, opensAt
useFormsLocale() / useFormsLocales() // current locale / available locales
useFormsPaths() // (name, params?) => resolved page path
useFormLink() // { enabled, url(slug), copy(slug) }
useFormStepper(...) // step navigation of the renderer
FORM_PASSWORD_HEADER // 'x-form-password'
```

## Utils

`@frigear-nu/forms/utils` is pure and safe in the Vue app and in Nitro.

| Export | Purpose |
| --- | --- |
| `defineForm`, `parseFormDefinition`, `formDefinitionSchema` | Author and validate definitions |
| `buildFormSchema`, `buildFieldSchema`, `validatedFields` | Compile a definition to zod |
| `evaluateCondition`, `resolveVisibility`, `isFieldVisible` | Conditional visibility |
| `resolveAccess`, `defaultAccess`, `accessSchema` | Effective access of a definition |
| `isFormOpen`, `nextFormOpening` | Open period |
| `composeEmail`, `renderTemplateText`, `renderTemplateHtml`, `unknownBodyVariables`, `availableVariables` | Email rendering |
| `composePhone`, `parsePhone`, `phoneCountries`, `allPhoneCountries` | Phone numbers |
| `resolveEmailDelivery`, `resolveCaptcha`, `renderMarkdown` | Delivery recipients, captcha provider, static markdown |
| `formsApi` | Typed paths of the HTTP API (`formsApi.submit(slug)`, `formsApi.admin.forms`, ...) |

The builder helpers (`moveField`, `insertField`, `setAccess`, ...) are exported from the same path.
