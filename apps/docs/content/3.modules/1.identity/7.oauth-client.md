::warning
`@frigear-nu/oauth-client` is **deprecated and frozen**. Use [Auth in client mode](/modules/identity/auth/client-mode)
(`authentication: { mode: 'client', client: {...} }`) instead.
::

The package stays as it is, so an app keeps working on the versions it has. It gets no new features and no translation
layer, and its last release logs a deprecation warning at build time.

- [Auth](/modules/identity/auth) refuses to run next to it, in either mode: both would register `$api` and `useApi`.
- [Mobile](/modules/interface/mobile) 0.2 signs in with Auth in client mode and refuses an `oauthClient` block. An app
  that is not ready to migrate stays on Mobile 0.1.
- `protect`, `publicPaths` and page meta `oauth` exist only here. In Auth, the guards belong to
  [Authorization](/modules/identity/authorization), and nothing is protected by default.

[Migrating from `@frigear-nu/oauth-client`](/modules/identity/auth/client-mode#migrating-from-frigear-nuoauth-client)
lists the seven steps and every renamed option, env var, hook and import.
