Guides follow one task from start to finish and link to the [module pages](/modules) for the reference. The first three
start a new project from a **starter**: a pnpm workspace in [`.starters/`](https://github.com/Frigear-nu/frigear-nu/tree/main/.starters)
that you copy with giget and that uses the published `@frigear-nu` modules.

| Guide | What it covers |
| --- | --- |
| [Workspace starter](/guides/workspace-starter) | A Nuxt 4 web app with sign-in, account pages and a user admin, and how to add modules. |
| [Mobile starter](/guides/mobile-starter) | A Capacitor app on [`@frigear-nu/mobile`](/modules/mobile) that signs in at frigear.nu or any OpenID Connect issuer, and how to add it to an existing workspace. |
| [Standalone mobile starter](/guides/mobile-standalone-starter) | The workspace starter plus the mobile app: the web app is the OAuth server and the API, wired to the app from one `identity.ts`. |
| [Use your own OAuth server](/guides/own-oauth-server) | What an issuer must provide for [`@frigear-nu/oauth-client`](/modules/oauth-client), with recipes for the Frigear OAuth server, frigear.nu, Keycloak, Auth0 and Zitadel. |

## Which starter?

| You have | Start from |
| --- | --- |
| Nothing yet, and want a web app | [Workspace starter](/guides/workspace-starter) |
| An issuer (frigear.nu, your own server, Keycloak, ...) and want a mobile app | [Mobile starter](/guides/mobile-starter) |
| Nothing yet, and want a mobile app with its own users and API | [Standalone mobile starter](/guides/mobile-standalone-starter) |
| A project from the workspace starter, and want a mobile app next to it | [Add apps/mobile to an existing workspace](/guides/mobile-starter#add-appsmobile-to-an-existing-workspace) |
