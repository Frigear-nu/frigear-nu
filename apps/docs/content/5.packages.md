In these docs, **packages** are shared libraries and tools that are not documented as Nuxt modules or layers. All of
these are workspace packages under `packages/` and are linked to other workspaces with pnpm's `workspace:*` protocol.

## Libraries and tools

- [`@frigear-nu/cli`](/packages/cli) — repository-specific command-line tools.

See [Modules](/modules) for Nuxt modules and [Layers](/layers) for reusable Nuxt configuration layers.
