---

Packages under `packages/` provide functionality reused by the applications and by one another. They are linked inside
the workspace with pnpm's `workspace:*` protocol.

## Packages

- [`@frigear-nu/base`](/layers/base) — shared Nuxt layer for website applications.
- [`@frigear-nu/module-kit`](/modules/module-kit) — common helpers for building Nuxt modules.
- [`@frigear-nu/users`](/packages/users) — user module used by the website.
- [`@frigear-nu/ui`](/packages/ui) — shared UI components and composables.
- [`@frigear-nu/oauth-server`](/packages/oauth-server) — Nuxt module with OAuth and OpenID Connect routes.
- [`@frigear-nu/cli`](/packages/cli) — repository-specific command-line tools.
