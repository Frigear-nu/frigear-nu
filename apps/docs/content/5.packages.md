---
title: Packages
description: Shared libraries and tooling in the workspace that are not Nuxt modules or layers.
---

Packages live under `packages/` and are linked with the pnpm `workspace:*` protocol. Nuxt modules are documented under
[Modules](/modules) and layers under [Layers](/layers).

| Package | What it is |
| --- | --- |
| [`@frigear-nu/cli`](/packages/cli) | Repository command-line tools, such as scaffolding a new module. |
| `@frigear-nu/eslint-config` | The shared ESLint configuration used by every workspace; published to npm as plain ESM (`export { default } from '@frigear-nu/eslint-config'` in an `eslint.config.mjs`). |
