**What you'll have afterwards:**

- A new feature in your app, such as forms, payments or events, with its pages in the admin area.
- Its tables in your database, through a committed migration.

Each module adds one feature to your [host app](/guide/concepts/glossary). It installs the modules it depends on, so you
usually add only the one you want. This page helps you pick a module and walks through adding one.

## Prerequisites

A project created in [Installation](/get-started/installation#_1-create-the-project).

## Add a module

Every module follows the same steps. This example adds [Forms](/modules/features/forms): forms stored in the database,
with admin pages to edit them and read submissions.

::tip
The [CLI](/contribute/tooling/cli) does steps 1 and 2 (install, and add to `modules`) in one go:
`pnpx @frigear-nu/cli add forms`. The options, the encryption key, the role grants and the migration are still yours.
::

::steps

### Install the module

Install it in the app, from the project root:

```bash
pnpm --filter ./apps/web add @frigear-nu/forms
```

### Add it to nuxt.config.ts

Add it to `modules` in `apps/web/nuxt.config.ts` and set its options. The module page lists them. It also lists what the
module needs from NuxtHub: Forms uses key-value storage (KV) for rate limiting and blob storage for uploads.

```ts [apps/web/nuxt.config.ts]
export default defineNuxtConfig({
  modules: [
    // ...
    '@frigear-nu/forms',
  ],
  hub: {
    kv: true,
    blob: true,
    db: { dialect: 'sqlite', driver: 'libsql', connection: { url: 'file:./.data/db/sqlite.db' } },
  },
  forms: {
    settings: {
      pages: { form: true, admin: true, adminForm: true, adminSubmissions: true, adminSubmission: true },
    },
  },
})
```

### Set its encryption key

:::warning
Without a key, Forms fails with a 500 as soon as it stores or reads a per-form secret.
:::

Forms encrypts per-form secrets in the database. The starter has no key it can fall back to, so add one to
`apps/web/.env` (and to your production environment), at least 32 characters, e.g. `openssl rand -base64 32`:

```bash [apps/web/.env]
NUXT_FORMS_ENCRYPTION_KEY=
```

Keep it stable: a new key makes the stored secrets unreadable.

### Give its permissions to a role

Your app decides who is staff, as it does for user management. Forms registers `forms:manage`, `forms:credentials` and
`forms:pii`, and gives them to the `admin` role by default (`grantTo`). To let another role manage forms, grant them in
`authorization.roles`:

```ts [apps/web/nuxt.config.ts]
export default defineNuxtConfig({
  authorization: {
    roles: {
      coordinator: { label: 'Coordinator', grant: ['forms:manage', 'forms:credentials'], inherit: ['user'] },
    },
  },
})
```

`forms:pii` (submission answers through MCP tools) is sensitive: a wildcard such as `forms:*` never covers it, so grant
it by name. Without [Authorization](/modules/identity/authorization) nobody holds a staff permission, unless your
`authorization:before` hook allows it.

### Generate the migration

:::warning
Without a migration the new tables do not exist, and every write to them fails.
:::

The module adds tables, so generate a [migration](/guide/concepts/glossary) and commit it:

```bash
pnpm db:generate
```

Run it after every module you add or upgrade. It prints `No schema changes, nothing to migrate` when the database is
already up to date.

### Restart the app

Restart `pnpm dev`. The new migration is applied on start.

::

::callout{color="success" icon="i-lucide-check"}
**What you should see:** a Forms entry in the admin area under `/admin`, open to users with the `admin` role.
::

## What a module page tells you

Each module page lists what the module needs under **Requires**, **Options** and **Hooks**:

- the other modules it installs or works with,
- the NuxtHub features it uses,
- the permissions it registers, and which roles get them by default,
- the environment variables it reads, such as Stripe keys.

A module declares the modules it depends on, and Nuxt installs them with it. So you list only the ones you want.
