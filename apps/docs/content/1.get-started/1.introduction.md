This repository is a pnpm workspace for Frigear's Nuxt applications and the reusable layer, modules and packages they
share. The main application is [`@frigear-nu/website`](/examples/apps/frigear-nu-website). Common functionality lives in modules
under `packages/`, so apps compose it instead of copying it.

::note
**Built for Nuxt 4.** The modules and the layer are Nuxt 4 modules (Nuxt `^4.6`) and expect the Nuxt 4 directory
structure (`app/` for app code, `server/` for server code). Nuxt 3 is not supported. Every setup snippet in these docs
is a Nuxt 4 `nuxt.config.ts`. To start a new app on them, copy a starter ([Quick start](/get-started/installation) helps you pick): the
[workspace starter](/examples/starters/workspace) for a web app, the [mobile starter](/examples/starters/mobile) or the
[standalone mobile starter](/examples/starters/mobile-standalone) for an iOS and Android app.
::

## Guides

Task-oriented walkthroughs are under [Guides](/examples/starters/workspace). To start with, see the [Quick start](/get-started/installation) to pick a starter: the [workspace starter](/examples/starters/workspace)
for a first web app, the [mobile starter](/examples/starters/mobile) and the
[standalone mobile starter](/examples/starters/mobile-standalone) for a mobile app, and [Use your own OAuth server](/guide/going-further/own-oauth-server) for pointing a browser or mobile app at an
issuer of your choice.

## Workspace map

| Folder | Kind | What lives there |
| --- | --- | --- |
| `apps/website` | [Application](/examples/apps/frigear-nu-website) | The Frigear website. Registers 17 modules on top of the base layer. |
| `apps/docs` | [Application](/contribute/documentation) | This documentation site, built with Docus. |
| `packages/base-layer` | [Layer](/modules/platform/base-layer) | `@frigear-nu/base`: shared Nuxt config, UI defaults and content-driven pages for websites. |
| `packages/<module>` | [Module](/modules) | One Nuxt module per concern, such as `users` or `stripe`. Published to npm as `@frigear-nu/<module>`. |
| `packages/cli` | [Package](/contribute/tooling/cli) | `@frigear-nu/cli`, a private tool that scaffolds new modules. |
| `packages/eslint-config` | Package | `@frigear-nu/eslint-config`, the shared lint rules. |

Modules and the layer are also workspace packages. They are linked with pnpm's `workspace:*` protocol, so run commands
from the repository root (see [Local development](/contribute/local-development)).

## Which module do I need?

Modules install their own dependencies automatically, so you usually add only the one you want.

| I want to... | Use |
| --- | --- |
| Let people sign in with a password, magic link, passkey or OAuth, and protect routes | [Auth](/modules/identity/auth) |
| Store users and manage them as staff | [Users](/modules/identity/users) |
| Decide who may do what, by role | [Authorization](/modules/identity/authorization) |
| Give users profile, security, documents and API token pages | [Account](/modules/identity/account) |
| Keep typed per-user settings | [Preferences](/modules/identity/preferences) |
| Act as an OAuth 2.0 / OpenID Connect provider | [OAuth Server](/modules/identity/oauth-server) |
| Accept frigear.nu sign-ins in another service (resource server) | [Frigear Resource](/modules/identity/frigear-resource) |
| Sign users in from a SPA or a Capacitor app with PKCE | [OAuth Client](/modules/identity/oauth-client) |
| Ship a Nuxt app as an iOS / Android app | [Mobile](/modules/interface/mobile) |
| Expose scoped tools to AI agents | [MCP](/modules/features/mcp) |
| Take payments or sell subscriptions with Stripe | [Stripe](/modules/commerce/stripe), [Payments](/modules/commerce/payments), [Subscriptions](/modules/commerce/subscriptions) |
| Run events with tickets and check-in | [Events](/modules/features/events) |
| Build forms stored in the database | [Forms](/modules/features/forms) |
| Show a cookie consent banner | [Cookie Consent](/modules/features/cookie-consent) |
| Build navigation, dashboard widgets or an admin area | [Menu](/modules/interface/menu), [Widget](/modules/interface/widget), [Admin](/modules/interface/admin) |
| Share UI components and dialogs | [UI](/modules/interface/ui) |
| Send email, SMS or other notifications | [Notify](/modules/platform/notify) |
| Write a new module | [Writing a module](/contribute/writing-a-module/scaffold), [Module Kit](/modules/platform/module-kit) |
