::tip{icon="i-lucide-rocket"}
**Want to build an app?** Go to [Installation](/get-started/installation#create-the-project): a few commands give you a
running Nuxt 4 app with sign-in, account pages and an admin area.
::

Frigear is a set of Nuxt 4 modules for the parts every web or mobile app needs: sign-in, users, an admin area,
payments, forms, events and more. You pick the modules you want, add them to `nuxt.config.ts` and configure them. This
repository is the pnpm workspace where they are built, published to npm as `@frigear-nu/<module>`, and used by the
[Frigear website](/examples/apps/frigear-nu-website).

::note
**Built for Nuxt 4.** The modules and the layer are Nuxt 4 modules (Nuxt `^4.6`) and expect the Nuxt 4 directory
structure (`app/` for app code, `server/` for server code). Nuxt 3 is not supported. Every setup snippet in these docs
is a Nuxt 4 `nuxt.config.ts`.
::

## Two paths

- **Build an app on Frigear.** Stay in this tab. You copy a starter, which uses the published packages and builds on
  its own, outside this repository. Start with [Installation](/get-started/installation).
- **Contribute to Frigear.** To change a module, the layer or these docs, work in this repository. Start with the
  [contribute overview](/contribute/overview).

## Workspace map

| Folder | Kind | What lives there |
| --- | --- | --- |
| `apps/website` | [Application](/examples/apps/frigear-nu-website) | The Frigear website. Registers 17 modules on top of the base layer. |
| `apps/docs` | [Application](/contribute/documentation) | This documentation site, built with Docus. |
| `packages/base-layer` | [Layer](/modules/platform/base-layer) | `@frigear-nu/base`: shared Nuxt config, UI defaults and content-driven pages for websites. |
| `packages/<module>` | [Module](/modules) | One Nuxt module per concern, such as `users` or `stripe`. Published to npm as `@frigear-nu/<module>`. |
| `packages/cli` | [Package](/contribute/tooling/cli) | `@frigear-nu/cli`, a private tool that scaffolds new modules. |
| `packages/eslint-config` | Package | `@frigear-nu/eslint-config`, the shared lint rules. |

An **application** is something you deploy. A **layer** is shared Nuxt config that an app extends. A **module** adds
one concern (routes, pages, tables, composables) to any app that installs it. A **package** is any other shared code.
Modules install the modules they depend on, so you usually add only the one you want.
