# Frigear Nuxt

This repository is a pnpm workspace for building Frigear's Nuxt applications and sharing reusable layers, modules, and
packages between them. The main application is [`@frigear-nu/website`](/applications/website); the source is organized
so common functionality can be reused instead of copied between apps.

## How the workspace fits together

- **Applications** are deployable products, such as the Frigear website and this documentation site.
- **Layers** provide reusable Nuxt configuration and application conventions. [`@frigear-nu/base`](/layers/base) is the
  shared foundation for websites.
- **Modules and packages** add reusable functionality. For example, [`@frigear-nu/users`](/packages/users) manages
  user-related functionality, and [`@frigear-nu/module-kit`](/modules/module-kit) provides helpers for building modules.

Workspace packages are linked with pnpm's `workspace:*` protocol. Run package commands from the repository root so
pnpm resolves those links correctly.
