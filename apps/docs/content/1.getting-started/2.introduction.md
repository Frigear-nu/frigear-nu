# Frigear

Frigear is a workspace for running a volunteer organization, with composable structure it is easy to build on.

## Shared packages

The apps use shared packages for schemas, API clients, and scraping functionality. In particular,
[profile-runner](/packages/profile-runner) extracts data from a website using a reusable profile. It supports browser
automation with Puppeteer as well as a faster, browser-free mode for static pages.
