This repository is a pnpm workspace for Frigear's Nuxt applications and the reusable layer, modules and packages they
share. The main application is [`@frigear-nu/website`](/applications/website). Common functionality lives in modules
under `packages/`, so apps compose it instead of copying it.

::note
**Built for Nuxt 4.** The modules and the layer are Nuxt 4 modules (Nuxt `^4.6`) and expect the Nuxt 4 directory
structure (`app/` for app code, `server/` for server code). Nuxt 3 is not supported. Every setup snippet in these docs
is a Nuxt 4 `nuxt.config.ts`. To start a new app on them, follow the [Quick start](/getting-started/quick-start).
::

## Guides

Task-oriented walkthroughs are under [Guides](/guides). Two to start with: the [Quick start](/getting-started/quick-start)
for a first app, and [Use your own OAuth server](/guides/own-oauth-server) for pointing a browser or mobile app at an
issuer of your choice.

## Workspace map

| Folder | Kind | What lives there |
| --- | --- | --- |
| `apps/website` | [Application](/applications) | The Frigear website. Registers 17 modules on top of the base layer. |
| `apps/docs` | [Application](/applications/docs) | This documentation site, built with Docus. |
| `packages/base-layer` | [Layer](/layers/base) | `@frigear-nu/base`: shared Nuxt config, UI defaults and content-driven pages for websites. |
| `packages/<module>` | [Module](/modules) | One Nuxt module per concern, such as `users` or `stripe`. Published to npm as `@frigear-nu/<module>`. |
| `packages/cli` | [Package](/packages/cli) | `@frigear-nu/cli`, a private tool that scaffolds new modules. |
| `packages/eslint-config` | Package | `@frigear-nu/eslint-config`, the shared lint rules. |

Modules and the layer are also workspace packages. They are linked with pnpm's `workspace:*` protocol, so run commands
from the repository root (see [Local development](/getting-started/local-development)).

## Which module do I need?

Modules install their own dependencies automatically, so you usually add only the one you want.

| I want to... | Use |
| --- | --- |
| Let people sign in with a password, magic link, passkey or OAuth, and protect routes | [Auth](/modules/auth) |
| Store users and manage them as staff | [Users](/modules/users) |
| Decide who may do what, by role | [Authorization](/modules/authorization) |
| Give users profile, security, documents and API token pages | [Account](/modules/account) |
| Keep typed per-user settings | [Preferences](/modules/preferences) |
| Act as an OAuth 2.0 / OpenID Connect provider | [OAuth Server](/modules/oauth-server) |
| Accept frigear.nu sign-ins in another service (resource server) | [Frigear Resource](/modules/frigear-resource) |
| Sign users in from a SPA or a Capacitor app with PKCE | [OAuth Client](/modules/oauth-client) |
| Ship a Nuxt app as an iOS / Android app | [Mobile](/modules/mobile) |
| Expose scoped tools to AI agents | [MCP](/modules/mcp) |
| Take payments or sell subscriptions with Stripe | [Stripe](/modules/stripe), [Payments](/modules/payments), [Subscriptions](/modules/subscriptions) |
| Run events with tickets and check-in | [Events](/modules/events) |
| Build forms stored in the database | [Forms](/modules/forms) |
| Show a cookie consent banner | [Cookie Consent](/modules/cookie-consent) |
| Build navigation, dashboard widgets or an admin area | [Menu](/modules/menu), [Widget](/modules/widget), [Admin](/modules/admin) |
| Share UI components and dialogs | [UI](/modules/ui) |
| Send email, SMS or other notifications | [Notify](/modules/notify) |
| Write a new module | [Writing a module](/getting-started/writing-a-module), [Module Kit](/modules/module-kit) |
