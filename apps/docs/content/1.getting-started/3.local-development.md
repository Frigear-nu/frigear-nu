## Requirements

The repository uses pnpm workspaces and declares its pnpm version in the root `package.json`. Enable Corepack to use
the package manager version declared by the project.

## Install dependencies

From the repository root:

```bash
corepack enable
pnpm install
```

Keep install, build, and test commands at the repository root. The workspace packages use `workspace:*` dependencies,
which pnpm resolves from there.

## Run an application

Start the main website or documentation site with a workspace filter:

```bash
pnpm --filter @frigear-nu/website dev
pnpm --filter @frigear-nu/docs dev
```

Each application starts its own Nuxt development server. Use the terminal output to open the local URL.

## Build and validate

```bash
pnpm --filter @frigear-nu/website build
pnpm --filter @frigear-nu/docs build
```

The root scripts also run workspace-wide linting, type checking, and tests:

```bash
pnpm lint
pnpm typecheck
pnpm test
```

See the root [README](https://github.com/Frigear-nu/frigear-nu#readme) for the workspace layout and additional
commands.
