Every published package under `packages/**` has a `.release-it.json`. Releasing bumps the version, commits, tags,
pushes, creates the GitHub release and publishes to npm.

## Release a package

1. Install dependencies from the repository root:

   ```bash
   pnpm i
   ```

2. Go into the package:

   ```bash
   cd packages/<your-package>
   ```

3. Release it:

   ```bash
   pnpm exec release-it <patch|minor|major|etc...>
   ```

4. If the release fails due to authentication, the version commit and tag are already pushed. Resume the npm publish:

   ```bash
   bash ../../scripts/npm-publish.sh
   ```

## Release from GitHub Actions

The **Release** workflow (`.github/workflows/release.yml`) does the same from the Actions tab. Pick a package and an
increment, or pick `all` to release every package one after another with the same increment.

When adding a new published package, give it a `.release-it.json` (copy a sibling's and change the name and tag), and
add it to the `package` choices and the `all` list in the workflow.
