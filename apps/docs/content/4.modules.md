## Modules

In these docs, a **module** is a Nuxt module that extends an application. Modules are distributed as workspace
packages, but are listed separately from general-purpose packages here.

- [`@frigear-nu/module-kit`](/modules/module-kit) — module and schema-extension helpers.
- [`@frigear-nu/users`](/modules/users) — user-related functionality and an extensible user database schema.
- [`@frigear-nu/oauth-server`](/modules/oauth-server) — OAuth and OpenID Connect server routes.
- [`@frigear-nu/ui`](/modules/ui) — shared UI components, composables, and Nuxt integrations.
