## Modules

In these docs, a **module** is a [Nuxt module](https://nuxt.com/docs/4.x/guide/modules) that extends an application. Modules are distributed as workspace
packages, but are listed separately from general-purpose packages here.

- [`@frigear-nu/module-kit`](/modules/module-kit) — module and schema-extension helpers.
- [`@frigear-nu/users`](/modules/users) — user-related functionality and an extensible user database schema.
- [`@frigear-nu/oauth-server`](/modules/oauth-server) — OAuth and OpenID Connect server routes.
- [`@frigear-nu/ui`](/modules/ui) — shared UI components, composables, and Nuxt integrations.
- [`@frigear-nu/notify`](/modules/notify) — email notification driver/dispatch module shared across modules.
- [`@frigear-nu/menu`](/modules/menu) — named, shareable navigation menus contributed to by other modules.
- [`@frigear-nu/stripe`](/modules/stripe) — generic Stripe core: customer linking, one verified webhook and an event-listener API.
- [`@frigear-nu/subscriptions`](/modules/subscriptions) — recurring subscriptions with host-defined plans, policy hooks and entitlements.
- [`@frigear-nu/payments`](/modules/payments) — one-time Stripe payments with lifecycle hooks driven by verified Stripe events.
- [`@frigear-nu/events`](/modules/events) — events with ticket types, addons, capacity, membership requirements and QR check-in.
