title: Applications
description: The deployable Nuxt applications in the Frigear workspace.
---

Applications live under `apps/` and are deployed independently. They consume modules, layers and packages through the
pnpm `workspace:*` protocol.

| Application | What it is |
| --- | --- |
| [Website](/applications/website) | The Frigear.nu website, composed from the shared modules and the base layer. |
| [Docs](/applications/docs) | This documentation site, built with Docus. |
