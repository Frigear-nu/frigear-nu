`@frigear-nu/cli` is a private [citty](https://github.com/unjs/citty) CLI for work inside this repository. It is not a
general-purpose tool for applications outside the workspace.

## Quick setup

Run it from the repository root through the root `cli` script:

```bash
pnpm cli --help
pnpm cli module:create --help
```

The script runs `packages/cli/bin/cli.mjs`, which loads the TypeScript source with `jiti`, so there is no build step.
Nothing needs to be installed beyond `pnpm install`.

## Commands

| Command | Purpose |
| --- | --- |
| `module:create` | Scaffolds a new Nuxt module under `packages/` from a template. |

### `module:create`

```bash
pnpm cli module:create <name> [--template <template>] [--cwd <dir>]
```

| Argument | Type | Default | Purpose |
| --- | --- | --- | --- |
| `name` | positional, required | none | Name of the module, for example `my-module`. It is kebab-cased. |
| `--template` | `string` | `gh:nuxt/starter#module` | A [giget](https://github.com/unjs/giget) template source, for example `gh:github.com/my/package`. |
| `--cwd` | `string` | `INIT_CWD`, else the current directory | Directory the `packages/` folder is resolved from. |

It downloads the template into `packages/<name>` and sets the `name` in its `package.json` to `@frigear-nu/<name>`. It
exits with an error, without changing anything, when `packages/<name>` already contains a `package.json`.

### After scaffolding

The command only creates the package. To make it a working workspace module:

1. Run `pnpm install` from the repository root.
2. Match the structure of a sibling module (tsconfig, build and test setup) instead of keeping the starter's.
3. To publish it, add a `.release-it.json` (copy a sibling's and change the package name and tag), and add the package to
   the `package` choices and the `all` list in `.github/workflows/release.yml`. See
   [Publishing packages](/getting-started/publishing).
4. Document it with a page under `apps/docs/content/5.modules/`, using the module page template in the
   [docs README](https://github.com/Frigear-nu/frigear-nu/blob/main/apps/docs/README.md#documentation-conventions), and
   add it to the root `README.md` package list.
