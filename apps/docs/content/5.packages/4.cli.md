## `@frigear-nu/cli`

The CLI package provides commands for use within this repository. It is private and is not intended as a general-purpose
CLI for applications outside the workspace.

From the repository root, invoke a command with the root package script:

```bash
pnpm cli module:create --help
```

`module:create` scaffolds a module under `packages/` and names it `@frigear-nu/<name>`.
