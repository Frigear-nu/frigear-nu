## `@frigear-nu/ui`

The UI package contains reusable Vue components and composables for Nuxt applications. Components are exported from
`@frigear-nu/ui/components/*`, and composables from `@frigear-nu/ui/composables`.

The package includes common form inputs such as date, currency, tag, interval, and URL inputs, as well as a confirmation
dialog composable. Check the package exports before relying on a component or composable in an app.

The package's [playground](https://github.com/Frigear-nu/frigear-nu/tree/main/packages/ui/playground) is available for
developing and previewing UI features.
