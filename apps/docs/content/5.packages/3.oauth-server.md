## `@frigear-nu/oauth-server`

This Nuxt module provides OAuth server routes for authorization, token exchange, revocation, and user information, as
well as OpenID Connect discovery and JWKS documents.

The package is marked private in its package configuration. Treat it as an internal workspace module rather than an
independently published package.
