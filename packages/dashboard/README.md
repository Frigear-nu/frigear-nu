# @frigear-nu/dashboard

Customisable dashboards: modules add items to a named dashboard with `extendDashboard` (on top of `@frigear-nu/widget`), pages render them with `<Dashboard>` or their own layout from `useDashboard`, and each user reorders, hides and collapses items (saved as a `@frigear-nu/preferences` preference when installed). With `@frigear-nu/mobile` it adds a Home tab.

See the [documentation](../../apps/docs/content/3.modules/7.interface/6.dashboard.md) for usage.
