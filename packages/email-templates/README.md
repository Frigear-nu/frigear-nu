# @frigear-nu/email-templates

Vue email templates for `@frigear-nu/notify`, rendered with [nuxt-email-renderer](https://nuxtemail.com): a typed `sendEmailTemplate(name, props, message)` for the host, and module emails (auth, users, subscriptions) rendered from templates the host can override by file name.

See the [documentation](../../apps/docs/content/3.modules/5.platform/3.email-templates/index.md) for usage.
